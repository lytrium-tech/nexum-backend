# NEXUM BACKEND V1.1 ROADMAP

## Objetivo

Backend V1 fue funcionalmente completado y permitió construir Frontend V1.

Durante la integración completa frontend-backend se detectaron inconsistencias de producto, verdad financiera y experiencia conversacional.

Backend V1.1 tiene como objetivo corregir dichas inconsistencias antes de una Alpha cerrada con usuarios reales.

La prioridad ya no es agregar módulos grandes.

La prioridad es:

```text
consistencia
verdad financiera
confianza del usuario
experiencia conversacional
```

---

# Principio Rector

El backend es la única fuente de verdad financiera.

Nunca:

```text
Frontend calcula métricas críticas.
LLM calcula métricas críticas.
```

Siempre:

```text
Backend calcula.
Frontend muestra.
LLM explica.
```
