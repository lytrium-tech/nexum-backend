# Mapa de Dominios

- **Users**: Gestión de perfiles, autenticación (Supabase JWT), bootstrap.
- **Accounts**: Billeteras o cuentas manuales.
- **Categories**: Categorización de ingresos y gastos.
- **Cash**: Transacciones en efectivo o cuentas (ingresos, gastos).
- **Goals**: Metas de ahorro.
- **Obligations**: Obligaciones o pagos recurrentes.
- **Credit**: Tarjetas de crédito y cuotas.
- **Intelligence**: Análisis financiero e insights con IA.
- **Conversations**: Chat interactivo procesado por Gemini NLP.
